# Independent validator audit, contracts at 21f7228

Reviewer: independent security subagent with no part in writing the contracts. Scope: `contracts/` validators and libraries. Method: code review against PRD 7, 11, 13.1, 16, ADR 0001, and the cardano-dev-skills review-contract checklist; proofs of concept as passing Aiken tests in a scratch copy (saved as `security/audit-poc-21f7228.ak`).

Baseline: `aiken check` 3,424 checks, 0 errors.

## Findings

| ID | Severity | Summary | Proof | Fix |
| --- | --- | --- | --- | --- |
| F1 | Critical | A parent subtracts a child's current `budget` from `committed` on close, but a child's budget shrinks when it pays out (AddressPayment, grandchild fee, Resolve worker share). `committed` never returns to 0 while `children_open` does, and CloseRoot, Cancel, Refund and SettleChild all require `committed == 0`. Any tree deeper than one level locks for good on the honest path. | `poc_settle_leaves_phantom_commitment`, `poc_stuck_root_cannot_close`, `poc_stuck_root_control` | ADR 0001 section 1.5: new `spent` field; `budget` never decreases; `committed` counts only open children |
| F2 | Critical | Anyone can make a logic credential's reward balance non-zero (pool retirement deposit refund to a pool whose reward account is the credential, or a governance deposit return). The ledger forces withdrawals to equal the balance, and the scripts required exactly 0, so every Cascade transaction would fail. | `poc_reward_balance_halts_protocol` | Accept any withdrawal amount; require only presence |
| F3 | Medium | CloseRoot's protocol-fee output had to carry zero lovelace, which min-UTxO rejects, when `protocol_fee_bps > 0`. The root would be stuck. Latent while the fee is 0. | `poc_protocol_fee_output_needs_zero_lovelace`, `poc_protocol_fee_control` | `protocol_lovelace` from `structural`, capped |
| F4 | Medium | The receipt operator could close a Metered channel before `timeout` and erase the provider's unredeemed vouchers. | `poc_payer_closes_channel_before_timeout` | Close only after `timeout` or with the provider's signature |
| F5 | Medium | With no arbiters or silent arbiters, the deadline exit favoured the parent and the challenger reclaimed its bond, so a challenge cost nothing (T7). | Code reading | Arbiter threshold at least 1 when Native leaves are allowed; Disputed deadline exit pays the worker its fee |
| L1 | Low | An operator can re-hire itself through leaf reuse up to `max_fee` per hire; plan leaves bind tasks, not agents. | Code reading | Off chain: signer plan-match and counterparty gates, buyer plan review (ADR 3) |
| L2 | Low | A tiny slash share can fall below min-UTxO, making SlashBond unbuildable; ReturnBond still works, nothing is stuck. | Code reading | Accepted; arbiters choose a buildable ruling |

Checked and found sound: voucher replay and signature domain, look-alike channels, fake `node_hash` isolation, mint exactness, output uniqueness, exact value checks, validity-range normalisation, amount sign checks, `publish` handlers, AddressPayment restrictions, the Masumi datum mapping (T5).
